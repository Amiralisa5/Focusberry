⚙️ Tracking levels

Level 1 — Always on: Tasks, Calendar, Cigarettes, Sleep, Focus/Energy. These never turn off — they're the minimum that keeps the app useful.
Level 2 — Optional: turn these on only while you actually want to log them. Fewer things to track most days means you'll actually keep doing it.
Level 3 — Experimental: anything you're curious about for 1–2 weeks, managed from the Experiments tab.

🔗 Manual multi-device sync

There's no live sync between devices — that needs a backend server. This is a manual, one-way workaround: generate a code on one device, paste and apply it on the other. Applying a code replaces all data on that device.

💾 Data

Everything lives only in this browser's local storage. Back it up if you clear your browser data or switch devices.
Want this installable on your phone with offline support? This file needs to be hosted (GitHub Pages, Netlify, or even python3 -m http.server locally) alongside the manifest.json and sw.js files included with this download — opening it directly from disk can't do real installs; that's a browser security rule, not a bug.
